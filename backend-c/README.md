# C Algorithm Implementations

This directory contains C implementations of the core algorithms used in the Cold-Chain Logistics Optimizer. 

**Note:** These files are for presentation and comparative analysis purposes only and are not currently integrated into the main Python/FastAPI application.

## Contents
- `dijkstra.c`: Shortest path algorithm with temperature-aware weights.
- `knapsack.c`: 0/1 Knapsack optimization using dynamic programming.
- `tsp_held_karp.c`: Exact TSP solution using bitmasking and DP.
